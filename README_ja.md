# 核磁気共鳴による量子コンピュータ・シミュレータ

ニールセン＆チャン『Quantum Computation and Quantum Information』7.7節（核磁気共鳴）の内容を学ぶための、ブラウザで操作できる2スピンのシミュレータです。

## 実験

| モード | 操作・観察できる内容 | 教科書との対応 |
| --- | --- | --- |
| RF rotation | RF位相、名目上の回転角、離調、各スピンの縮約状態のブロッホベクトル | 7.7.2節：回転座標系での単一スピンの運動 |
| J-coupled CNOT | Hz単位のJ結合、相互作用時間、途中の観測点、占有確率、複素密度行列 | 7.7.3節：制御ゲート |
| Refocusing | スピンAの周波数オフセット、待ち時間、パルスの有無、入力状態の回復 | 7.7.3節：リフォーカシング |
| NMR readout | 読み出しパルス、J結合、周波数オフセット、取得時間、T2、FID、位相情報を含むスペクトル | 7.7.2節：磁化の読み出しとデコヒーレンス |

操作例：

1. **J-coupled CNOT**で入力を`|+0⟩`のままにし、CNOTを実現する時間を選びます。`|00⟩`と`|11⟩`の占有確率がそれぞれ50%となり、対応する非対角成分は0.5になります。ベル状態では、各スピンの縮約状態のブロッホベクトルが0になります。
2. 擬純粋状態を選び、**Actual ρ**と**(ρ − I/4)/ε**を比較します。後者ではブロッホベクトルも拡大表示しますが、占有確率と重なりは常に実際の状態から計算します。
3. **RF rotation**で`|00⟩`にπパルスを加えた後、離調を増やします。共鳴時にはAが反転し、共鳴から外れると励起が抑えられます。
4. **Refocusing**で2つのπパルスの有無を切り替えます。パルスを加えると、列全体の終了時にAの周波数オフセットとBとの結合による時間発展が打ち消されます。
5. **NMR readout**で`|00⟩`にy軸まわりの読み出しパルスを加えると、Bの状態に対応する1本の線が現れます。`|++⟩`を選んで読み出しパルスを外すと、Jだけ離れた2本の線が現れます。縦方向の磁化しかない入力は、読み出しパルスなしでは信号を生じません。

## モデルと規約

基底の順序は`|00⟩, |01⟩, |10⟩, |11⟩`です。A（¹H）は最初のビットで制御、B（¹³C）は2番目のビットで標的です。Zは固有値が+1と−1のパウリ行列です。2スピンの状態を4 × 4の複素密度行列で表します。

周波数Jとδの単位は**Hz**、シミュレーション時間の単位は**秒**です。

```text
Hfree / ℏ = π δA ZA + π δB ZB + (π J / 2) ZA ZB
U(t)      = exp(−i Hfree t / ℏ)
δB        = 0
```

これは`Iz = Z/2`とした通常の弱結合の形`2π J IzA IzB`です。式(7.138)の結合定数を角周波数で表した場合の`Jangular = 2π JHz`に対応します。章内の他の式と比較するときは、この規約に合わせて数値を換算する必要があります。
初期値J = 215 Hzは、7.7.4節で扱われるクロロホルムの水素核と炭素核の結合です。

### RFとCNOT

```text
HRF / ℏ = [Δ Z + Ω(cos φ X + sin φ Y)] / 2
θ = Ω t, Ω/(2π) = 1000 Hz

UZZ(t) = exp(−i π J t ZA ZB / 2)
tCNOT  = 1/(2J) = 2.32558… ms for J = 215 Hz
```

時間順の演算列は`HB → UZZ(t) → RAz(−π/2) RBz(−π/2) → HB`です。CNOTを実現する時間では、全体位相を除いてCNOTと一致します。Hadamardゲートは`H ∝ Ry(π/2) Rz(π)`として構成でき、Z回転は理想的な座標系の位相変更として扱います。tを変えても局所位相の補正は固定されるため、t = 0で列全体が恒等演算になるわけではありません。

RFパルスは選択したスピンだけに作用し、パルス中の自由発展は無視します。RFモードでは、回転座標系で一定の駆動に対する離調の効果を厳密に計算します。ゲートのモードでは瞬間的な理想パルスを用い、緩和は含めません。

### リフォーカシング

時間順の演算列は`待機 t/2 → RxA(π) → 待機 t/2 → RxA(π)`です。Xパルスは`ZA`と`ZA ZB`の両方の符号を反転させるため、列全体では全体位相を除いて両者の時間発展が打ち消されます。`ZB`の項が0でなければその効果は残りますが、このモデルでは0としています。最後のパルスでスピンを元の座標系に戻します。

### 擬純粋状態

```text
ρ = (1 − ε) I/4 + ε |ψ⟩⟨ψ|
```

準備済みの擬純粋状態を入力として与えます。熱平衡、ラベリングの手順、特定の温度や磁場から決まる偏極はシミュレーションしません。ε = 0.1は学習用に信号を強調した値で、ε = 10⁻⁵は小さな偏極の例です。
拡大した偏差`(ρ − I/4)/ε`のトレースは0であり、密度行列ではありません。この表示に切り替えても、実際の確率や忠実度の計算から混合状態の背景成分が取り除かれるわけではありません。ベル状態を純粋成分に持つこの状態族がもつれるのは、ε > 1/3の場合だけです。

表示する重なりは、純粋状態を基準にした`F = ⟨ψideal|ρ|ψideal⟩`です。基準は、CNOTでは理想的な出力、RFでは同じ名目回転角での共鳴時の出力、リフォーカシングでは元の入力、読み出しでは読み出し用に準備した直後の入力です。プロセス忠実度ではありません。
理想的な擬純粋出力では、`F = (1 + 3ε)/4`、`Tr(ρ²) = (1 + 3ε²)/4`となります。

### FIDとスペクトル

受信信号の規約は`S = ⟨XA⟩ + i⟨YA⟩`です。教科書の`⟨iXA + YA⟩`とは、位相と複素共役の取り方が異なります。準備直後の密度行列に対し、信号は次の式で表されます。

```text
S(t) = exp(−t/T2) [2ρ20 exp(i2π(δA + J/2)t)
                  + 2ρ31 exp(i2π(δA − J/2)t)]
```

添字は0から3までの10進数の基底インデックスです。両方のスピンに独立な純粋位相緩和を適用し、密度行列の各成分を`exp(−d t/T2)`で減衰させます。dは、行と列の基底状態のビット列のハミング距離です。T1は無限大とし、占有確率は変化しません。

スペクトルは、`exp(−i2πft)`を用いた**無限時間の解析的フーリエ変換**を`ε T2`で割ったものです。表示している80 msのFIDを離散FFTしたものではありません。実部と虚部はそれぞれ吸収型・分散型の線を表し、吸収型の半値全幅は`1/(π T2)`です。対応するコヒーレンスが0なら、その遷移の線は現れません。ε = 0ではすべての信号が0となり、偏差の拡大表示は選択できません。
